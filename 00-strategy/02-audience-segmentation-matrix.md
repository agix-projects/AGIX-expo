# Audience Segmentation Matrix
## AGIX Agribusiness & Agritech Expo 2027

**Purpose:** This matrix defines every audience segment for the AGIX Agribusiness & Agritech Expo 2027 (9–10 April 2027, Amadeo Event Center, Enugu) with the profile, motivations, messaging, channels, call to action, decision timeline and owner for each. It is the reference for all outreach lists, campaigns and content plans.

**Owner:** Virtual Marketing Assistant (autonomous) / **Human approval required for:** segment prioritisation changes, pricing-linked offers, any outreach to government officials or sensitive institutional contacts, agreements arising from outreach.

**How to read the tables:** *Owner* = who executes ("Assistant" = fully automated; "Assistant + Human" = automated preparation with human-led meetings/signatures). *Decision timeline* = when this segment typically commits, mapped to campaign phases. All CTAs assume the relevant asset (prospectus, registration page) is live — see roadmap for dependencies.
