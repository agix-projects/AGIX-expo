## Editing & regenerating

`source/artboards.html` contains all six designs as pixel-sized artboards. Edit the
text/colours in that file, open it in a browser to preview, then screenshot each
artboard at its exact size (any full-page screenshot tool, or a headless browser
element capture) to produce updated PNGs.
