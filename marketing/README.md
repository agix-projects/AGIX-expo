## Editing & regenerating

`source/artboards.html` (launch set) and `source/artboards-about.html` (About-page
campaign set) contain all designs as pixel-sized artboards. Edit the text/colours,
open in a browser to preview, then screenshot each artboard at its exact size (any
screenshot tool, or a headless browser element capture) to produce updated PNGs.
