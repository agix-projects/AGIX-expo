# AGIX Pavilions — Brand Kit

Sub-brand for the hosted-pavilion programme of the AGIX Agribusiness & Agritech
Expo 2027 (country missions, state governments, trade groups and innovation
clusters — the Custom Booth / 36 sqm+ tier).

**Concept:** an amber canopy — the pavilion — shelters the AGIX wheat over field
rows: *a nation's agrifood story, hosted under one roof*. The mark inherits the
expo wheat so every pavilion is unmistakably part of AGIX.

## Palette

Inherits the expo palette (Night Forest `#0D2A14`, Deep Forest `#123B1D`,
Expo Green `#1A5227`, Growth Green `#2C9A46`, Harvest Amber `#F2A91E`,
Harvest Cream `#F3EAD8`) and adds one sub-brand accent:
**Pavilion Clay `#C26A2D`** — used for pavilion categories and wayfinding.

Category colour coding: Country = Harvest Amber, State = Growth Green,
Innovation = Pavilion Clay, Partner = White.

Typography: Archivo 800 (headlines/wordmark, uppercase) + Inter 400/600 (body).
